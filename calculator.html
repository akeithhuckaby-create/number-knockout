How it works: Set three dice values and press Calculate. The oracle tests every permutation of your dice with all operator and grouping combinations (+, −, ×, ÷, ^, √) to find which target numbers are reachable.

Free exponents: Any die can be raised to any power (0–6) without using a die. For example, 3^2 = 9 uses the die "3" but the exponent "2" is free.
Groupings tested: (a ∘ b) ∘ c  •  a ∘ (b ∘ c)  •  √a, √b, √c applied before operations.
