# Artwork and presentation

All nine raster assets were generated with OpenAI image generation for this Knight’s Path redesign in September 2026, using the user-approved fantasy tabletop direction. No stock library, third-party character property, or externally hosted image is required by the running game.

| File                  | Intended use and art direction                                                                                                                                 |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gold-knight.jpg`     | Original full-body gold-armored knight, brass plinth, readable silhouette. Reused for player portrait and moving piece.                                        |
| `blue-knight.jpg`     | Matching cobalt-blue and silver knight, pale crest, opposing facing direction. Reused for player portrait and moving piece.                                    |
| `crest.jpg`           | Navy enamel and aged-gold shield with a winding path toward a star. Header and browser icon.                                                                   |
| `dragon.jpg`          | Emerald dragon with gold highlights guarding a midnight stone lair. Welcome and board goal.                                                                    |
| `victory.jpg`         | Resting emerald dragon beside a golden crown; friendly, non-graphic celebration.                                                                               |
| `castle.jpg`          | Moonlit medieval castle landscape with quiet navy center and detailed perimeter. Page background.                                                              |
| `trail-landscape.jpg` | Illustrated wooded valley, gatehouse at lower left, distant keep, shadowed cliffs, and a warm lair ledge. Generated without numbers, routes, or player pieces. |
| `slate.jpg`           | Subtle slate-stone surface for live numbered stones.                                                                                                           |
| `wall.jpg`            | Reusable stone masonry and brass battlements, used as a material for trail and wall visuals.                                                                   |

Final artwork is optimized JPEG. Characters and crest have dark backdrops with CSS masks; they are not transparent PNG cutouts. Original generated PNGs and detailed prompts are preserved in the local review materials. This implementation choice keeps the illustrated silhouettes clean against the midnight interface.

All stone numbers, mathematical expressions, dice faces, buttons, and path connections are real HTML/SVG/CSS. No screenshot or concept image supplies gameplay text. Player letters and accessible names supplement Gold/Blue colors.

Typography uses local system sans-serif and Georgia/Times serif stacks. Sound is synthesized locally with Web Audio; no audio recording or music asset is downloaded. There are no external font requests.
